# Bundled GLSL shaders

Unmodified single-pass presets from [libretro/glsl-shaders](https://github.com/libretro/glsl-shaders):
`crt-pi`, `crt-lottes`, `crt-easymode`, `crt-geom` (CRT) and `lcd3x` (handheld LCD).
Each file keeps its original author and licence header (GPL or public domain).
These are GLSL for RetroArch's WebGL renderer; the sibling `slang-shaders` repo targets Vulkan/Metal and does not run in browsers.
